# PROYECTOS DESTACADOS

## 01 · Sistema de Solicitud de Documentos — UNERG

**Full Stack · Next.js · React · Node.js · Fastify · GraphQL · Prisma · PostgreSQL · Docker**

Plataforma web desarrollada para digitalizar el proceso de solicitud y entrega de documentos académicos de la **Universidad Nacional Experimental Rómulo Gallegos (UNERG)**.

El proyecto reemplazó un proceso que anteriormente requería gestiones presenciales y podía tardar varios meses. Desarrollé la solución de extremo a extremo, desde el análisis y diseño de la arquitectura hasta el desarrollo, integración de servicios y despliegue en producción.

**Principales aportes**

- Diseño y desarrollo de la arquitectura completa del sistema.
- Implementación del flujo de solicitudes, validación, procesamiento y entrega.
- Sistema de roles y permisos para estudiantes, asistentes y administradores.
- Automatización del cálculo y actualización de costos mediante la tasa de cambio oficial.
- Generación de documentos y reportes PDF con códigos QR de verificación.
- Notificaciones automáticas por correo.
- Bitácora de auditoría de las operaciones realizadas.
- Despliegue mediante Docker y Docker Compose.

**Resultado:** reducción del tiempo de entrega de documentos de **varios meses a aproximadamente 3 semanas**, además de la automatización de procesos administrativos que anteriormente se realizaban manualmente.

## 02 · Sistema de Recursos Humanos — UNERG

**Full Stack · Next.js · React · Node.js · Fastify · GraphQL · Prisma · PostgreSQL · Docker**

Plataforma de autoservicio desarrollada para el departamento de **Recursos Humanos de la UNERG**, permitiendo a los trabajadores solicitar documentos administrativos sin realizar el trámite presencialmente.

El sistema gestiona documentos como **constancias de trabajo, constancias de sueldo, carnet institucional, ARC y recibos de pago**.

**Principales aportes**

- Desarrollo completo de frontend, backend y base de datos.
- Sistema de autenticación y roles para administradores, asistentes y trabajadores.
- Integración con la base de datos legacy de nómina y contabilidad.
- Generación automática de documentos PDF con firma digital y códigos QR.
- Notificaciones automáticas por correo.
- Registro de auditoría de las operaciones del sistema.
- Implementación de medidas de seguridad y control de acceso.
- Despliegue mediante Docker y Docker Compose.

**Resultado:** digitalización de un proceso anteriormente presencial, reduciendo la carga operativa del departamento y mejorando la trazabilidad de las solicitudes.

## 04 · react-pdf-levelup

### Ecosistema de generación programática de PDFs

**React · TypeScript · Node.js · Vite · Fastify · Monaco Editor**

Proyecto de software propio orientado a la construcción programática de documentos PDF mediante componentes React reutilizables.

El proyecto evolucionó hasta convertirse en un ecosistema compuesto por una **librería core, IDE de desarrollo, documentación y playground**.

**Principales características**

- Componentes para tablas, códigos QR, códigos de barras y gráficos.
- Sistema de fuentes y gradientes.
- Renderizado asíncrono compatible con Node.js y navegador.
- Generación de PDFs desde backend.
- Procesamiento paralelo mediante worker threads y Piscina.
- IDE basado en React, Vite, Fastify y Monaco Editor.
- Documentación bilingüe con Astro/Starlight.
- Playground interactivo con editor y visor de PDF.

**Proyecto:** [react-pdf-levelup.nimbux.cloud](https://react-pdf-levelup.nimbux.cloud)

## 05 · Pipeline de migración de datos académicos

**Node.js · TypeScript · DBF · PostgreSQL · Prisma**

Pipeline desarrollado para migrar datos académicos desde sistemas universitarios heredados basados en archivos **DBF** hacia PostgreSQL.

Diseñado para procesar grandes volúmenes de información sin cargar todos los registros en memoria.

**Principales características**

- Procesamiento de archivos DBF.
- Pipeline desarrollado en Node.js y TypeScript.
- Migración hacia PostgreSQL mediante Prisma.
- Estrategia de carga invertida para optimizar memoria.
- Upsert atómico para evitar inconsistencias.
- Uso de `INSERT ... ON CONFLICT DO UPDATE`.
